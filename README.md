## 🎯 The Problem

Every year, thousands of families in Brazil lose their homes due to floods. Many of these tragedies could be prevented with early warnings and proper monitoring systems.

## 💡 Our Solution

Rio Alerta is a mobile application that transforms public river data into real protection for vulnerable communities through:

- **📊 Real-time Monitoring**: Tracks river levels continuously
- **📈 Pattern Analysis**: Analyzes historical data to identify flood risks
- **🔔 Automatic Alerts**: Sends notifications when flood danger is imminent
- **📍 Safe Shelters**: Maps nearby evacuation centers
- **📚 Education**: Provides tutorials on flood safety

- **Design**: Figma

## 📱 Features

### Home Screen
Displays current river level with visual indicators (Normal, Medium, High risk) and last update timestamp.

### Historical Data
Interactive charts showing river level variations over time, helping identify patterns and predict future risks.

### Shelter Map
Location-based information about the nearest safe shelters with directions via Google Maps integration.

### Safety Tips
Video tutorials and guides on how to protect your community during floods.

## 🚀 Quick Start

### Prerequisites
- MIT App Inventor account
- Android device (API level 21+)

### Installation
1. Download the latest `.apk` from [releases](https://github.com/DalPra0/RioAlerta/releases)
2. Enable "Install from unknown sources" on your Android device
3. Install and open the app

### Development
1. Clone this repository
2. Open `RioAlerta.aia` in MIT App Inventor
3. Make your changes
4. Export and test on your device
